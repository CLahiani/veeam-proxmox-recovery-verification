# legacy/ — v1 PowerShell implementation

**EN** — `Test-PveBackupBoot.ps1` is the original v1.0.0 implementation: PowerShell 7 on a Windows probe, driving the Proxmox node over SSH (key), with network-based application checks that required a probe NIC on the isolated VLAN. It is superseded by `../pve_backup_boot.py` (v2.0.0), which runs directly on the node and executes checks inside the guests through the QEMU guest agent. Kept for reference only; **not maintained**. Its configuration format (`RecoveryVerification.sample.json` here) includes an `Ssh*` section that the Python tool does not use.

**FR** — `Test-PveBackupBoot.ps1` est l'implémentation v1.0.0 d'origine : PowerShell 7 sur une sonde Windows, pilotant le nœud Proxmox en SSH (clé), avec des contrôles applicatifs réseau nécessitant une NIC de sonde sur le VLAN isolé. Elle est remplacée par `../pve_backup_boot.py` (v2.0.0), qui s'exécute directement sur le nœud et lance les contrôles dans les invités via le QEMU guest agent. Conservée pour référence uniquement ; **non maintenue**. Son format de configuration (`RecoveryVerification.sample.json` ici) comporte une section `Ssh*` que l'outil Python n'utilise pas.
